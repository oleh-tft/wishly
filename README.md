# Wishly

Студентський проєкт **Wishly** — платформа для створення та обміну вішлістами (списками бажань).

Репозиторій складається з двох частин:

| Частина | Технології | Папка |
|---------|------------|-------|
| **Frontend** | React 19, TypeScript, Vite, React Router | `frontend/` |
| **Backend** | Python, FastAPI, Pydantic | `backend/` |
